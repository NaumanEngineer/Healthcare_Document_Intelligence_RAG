# Two-Minute NHS Manager Explanation

I built a prototype designed to help NHS operational teams find current guidance more quickly and safely.

Operational staff may need to search across escalation policies, workforce procedures, bed-capacity guidance, winter-pressure plans and other governance documents.

The problem is not simply finding text. Staff need to know that the guidance is current, relevant and traceable.

My system processes the documents, keeps information such as the document version, status and page, and makes the content searchable by meaning.

When a manager asks a question, the system first identifies the most relevant current evidence.

Outdated or superseded guidance is excluded.

If the evidence is strong enough, the system passes only that approved evidence to the AI, which explains it in plain language and keeps the source attached.

If there is not enough evidence, the system is designed to say so rather than guess.

I also built separate checks to detect invented source references and to evaluate whether the answer appears supported by the evidence.

The intended benefit is faster access to guidance, better consistency, improved traceability and safer use of generative AI.

It is a decision-support prototype, not a replacement for NHS staff, formal policy or clinical judgement.
