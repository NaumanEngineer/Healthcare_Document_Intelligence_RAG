# Governance Principles

## 1. Evidence Before Generation

Generated answers should be based on retrieved source evidence.

The language model is not treated as the authoritative source.

## 2. Human Review

The system supports human decision-making rather than replacing professional or operational judgement.

## 3. Traceability

Every retrieved chunk should preserve sufficient metadata to trace it back to the original source.

## 4. Version Awareness

Document version, status and effective date should be preserved wherever available.

## 5. Data Minimisation

Only information required for the defined use case should enter the system.

## 6. Non-Sensitive Prototype

The portfolio implementation will use synthetic and publicly available non-sensitive information.

## 7. Insufficient Evidence

The system should abstain rather than fabricate an answer when supporting evidence is insufficient.

## 8. Retrieval Evaluation

Retrieval quality must be tested independently from answer fluency.

## 9. Security

User prompts and retrieved documents should be treated as untrusted inputs.

## 10. No Autonomous Actions

The prototype will not automatically trigger clinical or operational actions.

## 11. Explicit Limitations

Known limitations and unresolved source semantics should be documented rather than hidden.

## 12. Revalidation Before Production

A production healthcare implementation would require appropriate information-governance, security, clinical/operational safety and deployment review.
