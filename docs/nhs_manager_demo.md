# NHS Manager Demo

## 30-Second Explanation

This project is designed to help NHS staff find the right current operational guidance quickly and safely.

Instead of manually searching through multiple policy documents, a user can ask a normal question.

The system finds the most relevant current evidence, keeps the source and page attached, and only then allows AI to explain it.

If there is not enough reliable evidence, the system refuses to guess.

---

## Example Scenario

A manager asks:

"What should operational leadership do during escalation?"

The system:

1. searches current approved operational documents
2. finds the relevant escalation guidance
3. excludes outdated versions
4. checks the evidence is strong enough
5. explains the relevant guidance
6. shows the exact source
7. validates that the AI has not invented the citation

---

## Operational Benefit

The intended benefit is to reduce:

- document-search time
- use of outdated guidance
- inconsistent interpretation
- unsupported AI answers

while improving:

- traceability
- consistency
- auditability
- confidence in the evidence used

---

## Important Boundary

The system supports operational decision-making.

It does not replace managers, policies, clinical judgement or formal governance.

The human user remains accountable for the final decision.
